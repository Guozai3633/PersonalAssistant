# Personal Assistant Flutter Client

这是个人 AI 助手的 Flutter 客户端，提供记忆收件箱、快速录入、智能检索、待确认任务、语音舱和设置页。

## 启动

```powershell
flutter pub get
flutter run
```

## 测试

```powershell
flutter test
```

## 主要目录

```text
lib/
├── main.dart
├── models/       # 客户端数据模型
├── providers/    # Riverpod 状态管理
├── services/     # 后端 API 访问
├── utils/        # 加密、图谱聚类等工具
└── views/        # 页面与主要 UI
```

更多项目说明见根目录 `README.md`。
