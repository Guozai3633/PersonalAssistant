# 个人 AI 助手 (Personal AI Assistant) - PRD (产品需求文档)

## 1. 产品概述
在大学学习和日常生活中，我们会频繁接收到大量的碎片化信息（如学委发的课程群通知、突然冒出来的灵感、考试时间表的截图、需要临时记录的日程等）。传统的笔记软件（如 Notion, Obsidian）由于强调“文件夹/标签分类”的体系结构，导致**记录和整理的成本远高于信息本身的价值**，用户往往因为繁琐的整理流程而选择放弃记录，从而遗忘重要事件。

本项目旨在构建一个 **无感分类、去物理层级、AI 自动索引并呈现** 的个人智能助理。用户只需以最自然、最快的方式输入碎片化信息，系统在后台对数据进行清洗、分块、向量化与结构化存储，并能通过语义检索与精确时间线混合查询，为用户提供准确无幻觉的答复和炫酷的数据指标监控。

---

## 2. 核心设计原则
* **Storage ≠ Presentation（存储与呈现解耦）**：用户不关心文件或文字具体存在哪里。底层数据全部“黑盒化”拆碎存储，前端界面由 AI 检索并动态渲染成日历、待办事项列表、或潜意识瀑布流。
* **零摩擦录入**：移动端是主要入口。用户必须能通过“系统分享菜单”、“剪贴板自动嗅探”、“全局悬浮快捷录入”以及“语音/图片一键投递”完成信息捕获，消除输入壁垒。
* **BYOK (Bring Your Own Key) & 绝对私有化**：为极客用户提供模型接入配置。数据保存在本地 SQLite 和 Qdrant 中，支持本地 Ollama 运行，保障数据安全与隐私。

---

## 3. 核心功能需求

### 3.1 零摩擦录入 (Zero-Friction Capture)
* **文本与多媒体投递**：支持纯文本粘贴、多张图片上传（支持OCR解析）、语音录入。
* **剪贴板联动**：打开 App 时，嗅探系统剪贴板内容，检测到有效文本即弹窗提示“一键保存”。
* **系统级分享 (Share Extension)**：在第三方 App（如微信、浏览器）中长按或选择分享时，可直接通过本 App 投递到后台，无需打开 App 主界面。

### 3.2 极客仪表盘 (Data Vitals Dashboard)
作为 App 的主界面，用于提供用户数据资产的安全感和掌控感，取代空荡荡的聊天对话框：
* **已激活记忆体数**：展示 Qdrant 数据库中存储的 Embedding 向量总数和空间占用。
* **模型与流量监控**：
  * 云端模型：展示本月消耗的 Token 数量和预估费用折合。
  * 本地模型：展示当前手机/服务器的内存占用率和推理速度 (Tokens/s)。
* **今日数据吞吐量**：展示今天 AI 自动打标、清洗和归档的条目统计。
* **潜意识瀑布流 (Timeline)**：在仪表盘底部滚动展示 AI 后台默默对碎片信息打标签和向量化归档的实时日志，点击卡片可查看提取的结构化 JSON。

### 3.3 全局指令舱 (Command Center)
* 位于 Dashboard 顶部的万能搜索/输入框。
* 支持自然语言直接提问（如“我下周一早上有什么课？”），系统通过混合检索输出无幻觉答案。
* 支持快捷指令（如 `/todo 记得周五交物理实验报告`）以绕过 AI 提取直接写入结构化表。

### 3.4 混合检索与防幻觉 (Anti-Hallucination Retrieval)
对于日程、考试等高精确度信息，AI 必须给出 100% 准确的时间和地点：
* **双轨检索机制**：
  * **结构化轨**：入库时提取出具体的时间戳、标签、权重，存入 SQLite 表。查询时先用 SQL 严格筛选时间窗口。
  * **向量语义轨**：将文本段落向量化存入 Qdrant。查询时通过语义距离检索相关背景文件和资料。
  * **融合轨 (Rerank/Fusion)**：将 SQLite 精准数据和 Qdrant 语义上下文交由大模型做最终文本总结。
* **人工微调卡片**：AI 自动解析完录入信息后，在时间轴生成轻量确认卡片，允许用户对提取出的时间、优先级和标签进行手动确认/修正，防微杜渐。

---

## 4. 非功能性需求

### 4.1 数据安全性与隐私性
* 所有历史对话和结构化元数据均存储在本地 SQLite 数据库中。
* 向量库 Qdrant 在本地容器中运行，支持离线向量计算（如使用 Ollama 跑 embedding 模型）。
* 系统后端只做数据拼装转发，不持久化用户的任何 API Key。

### 4.2 性能与可观测性
* 本地混合检索响应时间应控制在 500ms 以内（不含大模型生成耗时）。
* Go 后端需具备完整的链路监控（Eino 运行图指标）以及结构化 slog 打印。
* 支持优雅停机，在更换模型配置或系统关闭时，正确取消正在进行的上下文请求并回收 Goroutine。
