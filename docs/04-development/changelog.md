# Changelog

## 2026-06-27

### Added

- 记忆后台解析状态与错误原因持久化。
- 失败或中断记忆的重试 API。
- Flutter 记忆卡片状态提示、一键重试和处理期间自动刷新。
- SQLite 旧数据迁移与处理状态回归测试。
- Flutter Memory JSON 状态兼容测试。
- AI 提取任务的待确认状态、原始记忆关联和原始时间表达。
- 任务确认 API，支持确认前修正标题、描述、类型与触发时间。
- Dashboard 待确认提醒卡片和来源原文展示。
- 任务确认调度边界及旧任务迁移回归测试。
- 不可变原始内容字段及旧数据库自动回填。
- 问答结构化记忆引用和按 ID 获取单条记忆接口。
- Flutter 可点击引用卡片与完整来源详情弹窗。
- 问答引用端到端组件测试。

### Changed

- 明文记忆改为先保存原文，再异步调用 AI。
- 图片 OCR 和元数据提取失败会明确标记失败，不再伪装为解析完成。
- 后台解析使用独立 Memory 与 AIConfig 快照，避免并发读写响应对象。
- 新提取的提醒默认不进入调度，只有用户确认后才转为可执行状态。
- 确认或忽略最后一条提取任务后，父记忆自动结束待确认状态。
- AI/OCR 处理内容与用户原始输入分离存储。
- 问答提示要求事实句标注引用编号，并返回同序来源摘要。
- 图片重复检测改为同时匹配解析内容和原始内容。
